# PROMPT 008 – GENERATE RELATIONSHIP CATALOG

## Objective

Generate executable Snowflake SQL required to create and populate RELATIONSHIP_CATALOG.

RELATIONSHIP_CATALOG is the curated relationship layer.

The purpose of this layer is to reduce the high-recall candidate pool generated by RELATIONSHIP_CANDIDATES into a smaller set of high-quality relationships suitable for:

* Business Rules
* Product Clustering
* Golden Record Creation
* Reporting

---

## Output Location

sql/intm/008_relationship_catalog.sql

Generate the contents of this file.

Do not generate any additional files.

## Relationship Ranking Rules

### Match Priority

T0 = 1

T1 = 2

T2 = 3

Lower number is better.

Generate:

MATCH_PRIORITY

---

## Best Match Selection Logic

For each:

LEFT_SOURCE_SYSTEM
+
LEFT_SOURCE_RECORD_ID

Select only the highest ranked relationship.

Ranking order:

1. MATCH_PRIORITY ASC

2. DQ_WEIGHTED_SCORE DESC

3. MATCH_SCORE DESC

4. RIGHT_SOURCE_SYSTEM ASC

5. RIGHT_SOURCE_RECORD_ID ASC

---

## Catalog Inclusion Rules

Only relationships selected as:

Best Match

should be included.

All lower ranked relationships must be excluded.

---

## IS_BEST_MATCH

Populate:

IS_BEST_MATCH = 'Y'

for all retained catalog records.
