PROMPT 018 – PIPELINE ORCHESTRATION PROCEDURE

Objective

Generate executable Snowflake SQL that creates a stored procedure capable of executing the complete Relationship Discovery and Master Data Management pipeline in the approved execution order.

This prompt implements a Platform Utility (PU).

The procedure shall provide a single entry point for executing the entire platform.

The procedure shall:

* Execute all approved SQL artifacts
* Execute artifacts in approved sequence
* Re-run DAL after each business rule
* Support repeatable execution
* Execute using EXECUTE IMMEDIATE FROM
* Execute using EXECUTE AS CALLER

The procedure shall not:

* implement business rules
* perform matching
* perform survivorship
* perform derivations
* perform DAL logic
* create source data
* modify governance metadata

The procedure is responsible only for orchestration.

---

Output

Generate SQL for:

sql/platform/018_pipeline_orchestration.sql

Generate only the SQL contents of this file.

Business Context

The Relationship Discovery Framework is composed of multiple independent SQL artifacts.

Each artifact has a single responsibility.

The platform shall execute artifacts in a controlled and approved sequence.

Business Rules generate actions.

DAL materializes actions.

The orchestration layer is responsible for ensuring DAL executes immediately after each Business Rule.
